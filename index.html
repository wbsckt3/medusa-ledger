Quick start

Clone, compose, post an event, verify the chain.

Clone the repository

git clone https://github.com/wbsckt3/medusa-ledger.git
cd medusa-ledger

Start the stack

docker compose up --build

Append an event

curl -X POST http://localhost:8080/api/events \
  -H "Content-Type: application/json" \
  -d '{
    "eventId": "order-001",
    "eventType": "ORDER_CREATED",
    "payload": { "customerId": "customer-42", "amount": 50000, "currency": "COP" }
  }'

Verify integrity

curl http://localhost:8080/api/verify
curl http://localhost:8080/api/ledger/show
